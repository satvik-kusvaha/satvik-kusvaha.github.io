## Food Chatbot

**Project description:** A restaurant food ordering chatbot powered by FastAPI and MySQL for efficient order management and data processing. Users interact with the system through natural language conversations to place, modify, and track their food orders. The chatbot maintains session-based order tracking, allowing users to add or remove items during an active order before confirming it. Once an order is completed, it is stored in a MySQL database where order items, pricing, and status are managed through stored procedures and queries. The system also supports real-time order tracking, enabling users to check the status of their order using an order ID. Additional backend utilities handle session parsing, order formatting, and database interactions to ensure smooth and reliable functionality.

**Goal:** Build an intelligent restaurant chatbot while demonstrating skills with FastAPI backend development, MySQL database integration, session management, and CRUD operations, while also simulating a real-world automated food ordering system.

**Result:** Developed a fully functional food ordering chatbot where users can interact conversationally to place orders, modify them, complete purchases, and track order status, all backed by a structured database and scalable API architecture.
